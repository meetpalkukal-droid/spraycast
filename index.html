      Wind at boom height

      Labels set wind limits at boom height [4], but forecasts give wind at 33 ft. The tool scales the 33 ft wind down with the FAO-56 logarithmic wind profile over short grass (Eq. 47) [10], using the boom's height above the ground. Because labels measure boom height above the crop, that is the crop height plus the boom height above the crop. FAO-56 states the equation in metric units, so heights are converted for the calculation only. The default is a 24 in boom (the label maximum above the target) over a 39.4 in crop, so the boom is about 5.3 ft above the ground, which gives about 71% of the 33 ft speed. Set your own boom and crop height in Advanced mode.

      The profile assumes neutral air. In calm, stable air near dawn and dusk, wind at the boom can be lower than shown. Measure wind at boom height in the field before spraying.

      Forecast data

      Hourly forecasts come from Open-Meteo [8]. For about the first 48 hours they use NOAA's 2-mile-grid HRRR model [9], and NOAA's GFS after that. Each pin uses the forecast for the model grid cell that contains it, with no interpolation. Forecasts refresh hourly, and later days are less certain.
